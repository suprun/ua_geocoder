# UA Geocoder

Плагін для роботи з Visicom Data API у QGIS: пошук адрес і об’єктів,
зворотний пошук за точкою та показ геометрії на карті. Основні вкладки — «Пошук» і «Налаштування».

## Сумісність

Заявлена сумісність: QGIS 3.28–4.99, Qt5/Qt6. Для запитів до сервісу
потрібне підключення до інтернету.

## Встановлення

1. У QGIS відкрийте «Модулі → Керування та встановлення модулів → Встановити з ZIP».
2. Виберіть отриманий архів `ua_geocoder.zip` і встановіть модуль.
3. Увімкніть UA Geocoder у списку встановлених модулів.

## Перший запуск

1. Відкрийте вікно плагіна та перейдіть на вкладку «Налаштування».
2. Виберіть спільний доступ Railway або режим «Власний ключ Visicom API».
   Для власного доступу введіть ключ і натисніть «Зберегти».
   Зміни режиму доступу також потрібно зберегти.
3. Якщо QGIS запитає головний пароль Authentication Manager, задайте або введіть його.
4. На вкладці «Пошук» виберіть режим адреси, введіть адресу та натисніть
   Enter або «Знайти». Виберіть потрібний результат у списку.

Адресний пошук також доступний у Locator QGIS, наприклад:
`укр Київ, Хрещатик, 26`.

## Категорії й результати

Адресні результати мають два стовпчики: «Знайдений результат» і «Категорія».
Клік у будь-якому стовпчику обирає рядок для копіювання та перегляду на карті.
Порядок сервісу зберігається; ширину стовпчиків можна змінювати.
Locator і таблиці показують назви категорій в однині. Наприклад,
`poi_express_mail,poi_delivery` → «Експрес-пошта, Доставка»; невідомі коди не підміняються.
Прямий адресний пошук і локальний сервер запитують до 20 результатів.

Вибрані категорії об’єктів зберігаються між сесіями в поточному профілі QGIS,
включно з Undo/Redo і порожнім вибором. Скасування діалогу зберігає попередній перелік.
У переліку вибору залишаються назви категорій у множині.

## Доступ і квоти

- **Спільний доступ Railway:** власний ключ Visicom не потрібний;
- **Власний ключ Visicom:** запити надсилаються із власним ключем Visicom API.
  Ключ вводиться в налаштуваннях плагіна.

Секрети зберігаються через QGIS Authentication Manager.

Запити обмежуються квотами обраного доступу. Кешовані повтори не витрачають
квоту; отримання повної геометрії вперше може потребувати окремого запиту.
Лічильник власного ключа є локальною оцінкою використання цим плагіном
на комп’ютері й не враховує інші програми або комп’ютери.
